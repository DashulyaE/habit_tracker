# Трекер привычек 
## Описание проекта:
В данном приложении реализована бэкенд-часть SPA веб-приложения трекер привычек

## Установка:

Клонируйте проект в свой репозиторий по ссылке:
```
git clone github.com/DashulyaE/habit_tracker
```

## Документация

Ознакомиться с документацией проекта можно, запустив сервер коммандой в терминале:
```
python manage.py runserver
```
И введя адрес в браузере:
```
http://127.0.0.1:8000/swagger/
```
